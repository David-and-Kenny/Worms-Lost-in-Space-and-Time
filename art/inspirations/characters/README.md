Compare the images below before choosing a direction. Each has paired source and
feedback notes. Adding them as references does not approve a redesign.

The face-visible pixel sheet and visor-covered illustrations differ in rendering
style as well as helmet treatment. They have not been established as matching
mask-on/mask-off states of one animation. The body parts are included as supporting
art. Record which attributes to carry forward in the matching Markdown notes.
