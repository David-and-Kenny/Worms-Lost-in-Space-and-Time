# Pipe level-selection revision

Direction requested by the owner: replace the cogs around level labels with
pipe-themed buttons and connect levels with smaller pipes. The existing space
backdrop, fonts, character, footer controls and settings remain the same.

Both world selectors use a copper pipe frame around a dark teal label inset.
Thirteen thin, duller pipe segments connect adjacent buttons into a plumbing
network. Connections are decorative and do not indicate a new unlock rule.
Existing level order, labels, locked states, stars and navigation are retained.
The two-column portrait/five-column landscape layout is retained.

Source images are `level-pipe-button.png` and `level-link-pipe.png` beside this
file; production sprites are under `Assets/Artwork/Menus`. The cog sprite is
still used behind the unchanged character on the start/main screens and remains
in place. Existing legacy image and prefab backups are retained.

`MenuArtTools.Apply` authors the connection Images as a sibling layer behind the
level grid. Serialized RectTransform references let MenuLevelGrid position them
when the layout changes; it creates no UI objects at runtime. Connections and
status badges have raycasting disabled. The actual level button faces handle
input through the existing persistent callbacks.

The source frame's center has partial alpha. A serialized opaque teal inset
behind each face prevents the decorative pipe network showing through labels;
the source generation and transparent exterior are preserved.

Generated with built-in Imagegen using the current menu button and observatory
background as visual references. Both outputs have transparent alpha. Exact
prompts follow.
